# Reporting a security issue

Use GitHub's private vulnerability reporting on the repository's Security tab when available. If the private channel is unavailable, open an issue asking a maintainer for a private contact channel. Keep vulnerability details in the private report.

Include the affected version, platform, expected trust boundary and a minimal description using synthetic devices or files. Redact peer addresses, receiver identifiers, passwords, clipboard contents, private paths and the complete state file. Use Flow with trusted devices on a trusted LAN and scope firewall access to the intended peers.
